# Paris Weather Streaming

Big Data project: we collect the weather in Paris every 15 minutes and predict if it will be **cloudy** or **windy in the next hour**.

## Team
- Grace Diagoné


## Data
- **Source:** Open-Meteo, Météo-France API (`https://api.open-meteo.com/v1/meteofrance`)
- **Protocol:** REST, JSON
- **Frequency:** every 15 minutes
- **Licence:** CC BY 4.0, weather data by Open-Meteo.com (no API key needed)
